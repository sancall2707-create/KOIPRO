Panduan Instalasi

Prasyarat

Install software berikut sebelum memulai:

SoftwareKeteranganDownload
LaragonSudah termasuk PHP 8.x, MySQL, Composerlaragon.org
GitUntuk clone repository (opsional)git-scm.com
Catatan: Laragon sudah mencakup semua yang dibutuhkan (PHP, MySQL, Composer). Tidak perlu install ketiganya secara terpisah.

Langkah Instalasi

1 Salin / Clone Project

Opsi A – Salin manual: Copy seluruh folder laravel-app ke device baru. Hapus folder vendor/ sebelum dicopy (akan dibuat ulang).

Opsi B – Via Git:

git clone <url-repo> laravel-app
cd laravel-app

2 Install PHP Dependencies

Buka terminal di dalam folder laravel-app:

composer install

Jika Composer belum ada di PATH (Laragon), jalankan dulu:

$env:PATH = "C:\laragon\bin\php\php-8.3.30-Win32-vs16-x64;C:\laragon\bin\composer;" + $env:PATH
composer install

3 Buat File Konfigurasi .env

Copy file contoh konfigurasi:

cp .env.example .env

Kemudian generate application key:

php artisan key:generate

4 Atur Koneksi Database di .env

Buka file .env dengan text editor, sesuaikan bagian berikut:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=kopipro
DB_USERNAME=root
DB_PASSWORD=
Password dikosongkan jika menggunakan Laragon default. Jika MySQL punya password, isi sesuai password Anda.

5 Buat Database

Buka phpMyAdmin di browser: http://localhost/phpmyadmin

  • Klik "New" di panel kiri
  • Masukkan nama database: kopipro
  • Collation: utf8mb4_unicode_ci
  • Klik tombol "Create"

6 Jalankan Migrasi & Seeder

Perintah ini membuat semua tabel dan mengisi data awal:

php artisan migrate --seed

Data yang akan dibuat secara otomatis:

  • Tabel: admins, categories, products, orders, order_items, coffee_tables
  • 1 akun admin default
  • 5 kategori menu
  • 8 produk menu
  • 10 meja kafe
Akun Admin Default
Username: admin  |  Password: admin123
Segera ganti password setelah login pertama.

7 Set Permission Storage (Linux / Mac saja)

Lewati langkah ini jika menggunakan Windows.

chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

8 Jalankan Server

php artisan serve

Buka browser dan akses:

HalamanURL
Beranda / Menuhttp://localhost:8000
Admin Loginhttp://localhost:8000/admin/login
Admin Dashboardhttp://localhost:8000/admin

Ringkasan Semua Perintah

Copy & Paste ke Terminal
composer install
cp .env.example .env
php artisan key:generate
# Edit file .env → sesuaikan DB_DATABASE, DB_USERNAME, DB_PASSWORD
php artisan migrate --seed
php artisan serve

Catatan Penting

HalKeterangan
Folder vendor/Jangan dicopy — dibuat ulang via composer install
File .envJangan dicopy jika beda server — buat dari .env.example
Port MySQLLaragon default 3306, XAMPP kadang 3307 — sesuaikan di .env
PHP VersionGunakan PHP 8.1 ke atas. Cek dengan php -v
ComposerCek dengan composer --version. Butuh versi 2.x
Storage LinkJika ada file upload, jalankan php artisan storage:link
